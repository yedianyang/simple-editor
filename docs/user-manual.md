# FieldCorder DAW 使用说明书

## 一、项目简介

FieldCorder 是一款专为 macOS 设计的轻量级数字音频工作站（DAW），专注于多声道环境录音编辑。支持 2-6 声道音频，并提供 VST3/AudioUnit 插件托管功能。

---

## 二、主要功能

### 2.1 多声道轨道
- **轨道类型**：Mono（1声道）、Stereo（2声道）、Quad（4声道）、5.1（6声道）
- **声道徽章**：每条轨道的表头显示声道类型标记——[M]、[ST]、[Q]、[5.1]
- **分声道波形显示**：多声道轨道内各声道以堆叠子通道（stacked sub-lanes）形式呈现，1px 分隔线分割
- **颜色编码**：每个子通道使用独立颜色（L=蓝、R=绿、Center/Rear L=琥珀、LFE/Rear R=红、LS=紫、RS=粉）
- **原子操作**：多声道 clip 是单一对象（`bufferIds[]` 包含各声道数据），移动、修剪、删除、Undo 均作用于整体
- **严格通道匹配**：Clip 的声道数必须与目标轨道一致；不兼容拖放时 ghost clip 变红，拒绝放置

### 2.2 音频插件
- **内置效果器**（无需额外安装）：
  - 3 段均衡器（EQ）
  - 高通滤波器（HPF）
  - 低通滤波器（LPF）
  - 压缩器（Compressor）
  - 混响（Reverb）
  - 延迟（Delay）
  - 增益（Gain）
- **第三方插件**：VST3 / AudioUnit（需编译原生插件）

### 2.3 专业电平表
- 实时峰值（Peak）
- RMS 电平
- True Peak（真峰值）
- LUFS 响度（ITU-R BS.1770-4）

### 2.4 通道混音器
- 每声道独立音量控制
- 静音（Mute）
- 独奏（Solo）
- 效果器插入

### 2.5 多文件工作流
- 拖放导入
- 文件队列管理
- **文件浏览器拖放到时间线**：从文件浏览器拖放文件到时间线上的指定位置

### 2.6 频谱分析
- 实时 FFT 显示
- 可配置窗口大小

### 2.7 非破坏性编辑
- 完整撤销/重做历史

## 四、基本操作

### 4.1 导入音频

**方式一：拖放到编辑区**
- 将 WAV、AIFF 文件拖到编辑区

**方式二：菜单**
- `File` → `Import Audio` 或 `Cmd + O`

**方式三：文件队列**
- 点击工具栏 `Add Files` 添加多个文件

**方式四：从文件浏览器拖放到时间线**
- 从左侧文件浏览器拖拽文件到时间线上
- 拖拽时蓝色高亮预览目标轨道，虚线标记插入时间位置
- 松开后文件在指定位置加载，不会清除现有内容
- `Cmd + Z` 可撤销导入

**多声道 WAV 导入行为：**
- 多声道 WAV（2ch/4ch/6ch）导入后创建一条多声道轨道，而非 N 条单声道轨道
- 创建**一个** clip 对象，内含各声道 buffer（`bufferIds[]`），在同一轨道内以堆叠波形显示
- 采样率不匹配时弹出确认对话框；点击"取消"不导入（不进行任何操作）

### 4.2 播放控制

| 操作 | 快捷键 |
|------|---------|
| 播放/暂停 | `Space` |
| 循环开关 | `L` |
| 倒放 | `R` |

### 4.3 编辑操作

| 操作 | 快捷键 |
|------|---------|
| 全选 | `Cmd + A` |
| 删除选区 | `Delete` / `Backspace` |
| 修剪到选区 | `Cmd + T` |
| 淡入 | `Cmd + F` |
| 淡出 | `Cmd + Shift + F` |
| 新建轨道 | `Cmd + Shift + N` |
| 增益 | `Cmd + G` |

### 4.4 缩放

| 操作 | 快捷键 |
|------|---------|
| 放大 | `+` / `=` |
| 缩小 | `-` |
| 左移播放头 | `←` |
| 右移播放头 | `→` |

### 4.5 标记点

- 添加 cue 点：`M`
- 删除 cue 点：选中后 `Delete`

### 4.6 创建多声道轨道

**方式一：快捷键**
- `Cmd + Shift + N` 打开"New Track"对话框

**方式二：右键菜单**
- 右键点击轨道表头 → 选择"New Track..."

**方式三：菜单**
- `Edit` → `New Track`

**对话框选项：**
- **Name**：轨道名称
- **Type**：选择声道类型
  - Mono（1声道）
  - Stereo（2声道）
  - Quad 4.0（4声道）
  - 5.1 Surround（6声道）

### 4.7 调整轨道高度

- 将鼠标移至轨道表头底部边缘，光标变为 `↕`（ns-resize）
- 按住鼠标上下拖拽调整轨道高度
- 最小高度限制：声道数 x 24px（例如 Stereo 最小 48px，5.1 最小 144px）

### 4.8 跨轨道拆分与合并

**立体声 clip → 单声道轨道（拆分）**
- 将立体声 clip 拖到单声道轨道上，系统自动将 L/R 分入两条单声道轨道
- 如果只有 1 条单声道轨道，系统会在底部自动新建第二条单声道轨道
- 拆分后原来的立体声 clip 被移除，可通过 `Cmd+Z` 撤销

**2 个单声道 clip → 立体声 clip（合并）**
1. 在时间线上选中 2 个单声道 clip（使其时间位置相同）
2. 右键点击 → "Merge to stereo track"
3. 生成一个新立体声 clip，并在立体声轨道上放置

**不允许的操作**
- 单声道 clip 拖入立体声轨道：ghost clip 变红，放开后不执行
- 通道数不匹配且无法拆分时：同样拒绝（红色提示）

### 4.9 淡变曲线调整

每条 clip 的淡入/淡出区域支持曲线形状调整：
- 先移动鼠标到 clip 的淡入或淡出手柄区域
- **上下拖动**手柄：调整曲线指数，范围 -1（凸形）到 +1（凹形），0 为线性
- 曲线变化实时渲染到波形上

### 4.10 Crossfade（交叉淡变）

- 将两个 clip 重叠放置或通过拖拽重叠区域可创建 crossfade
- **双击** crossfade 区域可在 `equalPower` 和 `equalGain` 模式间切换
- Crossfade 区域内两个 clip 的波形**同时可见**（半透明叠加，Pro Tools 风格）
- 琥珀色覆盖层标识 crossfade 区域范围

### 4.11 撤销/重做

| 操作 | 快捷键 |
|------|---------|
| 撤销 | `Cmd + Z` |
| 重做 | `Cmd + Shift + Z` |

## 五、混音器使用

### 5.1 通道控制
每声道包含：
- **音量推子**（Volume）
- **静音**（Mute）：点击立即生效，包括播放中实时切换
- **独奏**（Solo）：点击立即生效，播放中同步更新；其余未独奏轨道自动静音
- **效果器插槽**：最多 4 个效果器

### 5.2 添加效果器
1. 点击通道上的 `+` 按钮
2. 从效果器列表选择：
   - 3-Band EQ
   - HPF / LPF
   - Compressor
   - Reverb
   - Delay
   - Gain
3. 调整参数

---

## 六、效果器说明

### 6.1 3-Band EQ
- **Low**：低频增益（-12dB ~ +12dB）
- **Mid**：中频增益（-12dB ~ +12dB）
- **High**：高频增益（-12dB ~ +12dB）

### 6.2 Compressor
- **Threshold**：阈值（-60dB ~ 0dB）
- **Ratio**：压缩比（1:1 ~ 20:1）
- **Attack**：启动时间（0.1ms ~ 100ms）
- **Release**：释放时间（10ms ~ 1000ms）

### 6.3 Reverb
- **Decay**：衰减时间（0.1s ~ 10s）
- **Wet/Dry**：干湿比（0% ~ 100%）

### 6.4 Delay
- **Time**：延迟时间（0ms ~ 5000ms）
- **Feedback**：反馈（0% ~ 90%）

## 七、导出

### 7.1 导出音频
1. `File` → `Export` 或 `Cmd + E`
2. 选择格式：
   - **WAV**：16-bit / 24-bit / 32-bit Float
   - **AIFF**：16-bit / 24-bit / 32-bit
3. 选择声道布局（Stereo / Quad / 5.1）
4. 可选：dithering（TPDF / Noise-shaped）

### 7.2 保存项目
- `File` → `Save` 或 `Cmd + S`
- 保存为 `.fcproj` 文件（JSON 格式，含嵌入音频数据）

## 十、故障排除

### 10.1 音频无声音
- 检查系统音量设置
- 确认播放头位置
- 检查通道是否静音

### 10.2 导入失败
- 确认文件格式支持
- 检查文件是否损坏

### 10.3 VST/AU 插件不工作
- 需要编译原生插件（见开发文档）
- 检查插件是否支持当前系统架构
