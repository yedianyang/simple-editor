# Design Decisions

记录重要的架构和设计决策。

## 何时记录

- 技术选型（框架、库、工具）
- 架构变更（模块划分、数据流）
- 性能优化策略
- API 接口设计
- 格式兼容性决策
- MAS 限制相关的设计权衡

## 文档格式

文件命名：`YYYY-MM-DD-简短标题.md`

```markdown
# [决策标题]

**日期**: YYYY-MM-DD
**决策者**: [agent/人工]
**状态**: 已采纳 / 已废弃 / 待定

## 背景

简述问题和上下文。

## 决策

我们决定 [做什么]。

## 理由

为什么这样做：
- 原因 1
- 原因 2

## 后果

这个决策的影响：
- 积极影响
- 消极影响
- 风险

## 备选方案

考虑过但未采纳的方案及原因。
```
