### 文件状态标记

| 图标 | 状态 | 说明 |
|------|------|------|
| 🔄 | `pending` | 待处理（默认状态） |
| ✅ | `done` | 已处理（用户手动标记或导出后自动标记） |
| ❌ | `skipped` | 已跳过（用户明确跳过不处理的文件） |

### 交互行为

- **单击文件**：加载到中央编辑区
- **右键菜单**：标记已处理 / 标记跳过 / 重置状态 / 在 Finder 中显示
- **拖拽文件夹**：到 "📁 打开文件夹" 按钮上，快速加载整个文件夹
- **键盘导航**：↑/↓ 切换文件，Enter 加载，Space 预览
- **搜索**：实时过滤文件名，支持通配符（`*.wav`, `amb*`）

### Cue Points 交互

- **添加 Cue Point**：右键时间标尺 → "Add Cue Point" → 输入名称
- **跳转**：点击 Cue Points 栏中的标签，播放头跳转到对应位置
- **快捷键**：`1` 跳转到 Cue A，`2` 跳转到 Cue B，`Home` 跳转 Start，`End` 跳转 End
- **删除**：右键 Cue Point → "Delete"

### Crossfader 详解

```
Crossfader:

  Track 1  ◀────────●────────▶  Track 2
           A      -3dB       B
           Law: Equal Power

操作:
  - 拖拽中间的 ● 滑块，在 Track A/B 之间交叉淡入淡出
  - 完全左侧：100% Track A，0% Track B
  - 中间 (0dB)：两者平衡混合
  - 完全右侧：0% Track A，100% Track B
  - Law 选择：Equal Power (默认) 或 Equal Gain
```

## 6. Clip 交互说明

### 操作表

| 操作 | 行为 | 光标样式 |
|------|------|----------|
| **点击空白时间线** | 移动播放头到点击位置 | 默认箭头 |
| **点击 Clip 中间** | 选中该 Clip（蓝色边框高亮） | 默认箭头 |
| **双击 Clip** | 重命名 Clip | 文本输入 |
| **拖拽 Clip 中间** | 水平移动 Clip（不改变时长） | 四向箭头 ↔️ |
| **拖拽 Clip 左边缘** | 裁剪起始点（时长变化） | 左右箭头 ◀▶ |
| **拖拽 Clip 右边缘** | 裁剪结束点（时长变化） | 左右箭头 ◀▶ |
| **S 键** | 在播放头位置分割选中 Clip（生成两个 Clip） | - |
| **Delete / Backspace** | 删除选中 Clip（释放时间线空间） | - |
| **Cmd+C** | 复制选中 Clip | - |
| **Cmd+V** | 粘贴 Clip 到播放头位置 | - |
| **Cmd+D** | 复制 Clip 到其后方（紧挨着） | - |
| **Cmd+Z** | 撤销上一步编辑操作 | - |
| **Cmd+Shift+Z** | 重做下一步编辑操作 | - |
| **拖拽 Clip 到其他 Track** | 移动到新 Track（垂直移动） | 四向箭头 |
| **Alt + 拖拽 Clip** | 复制 Clip 到新位置 | 带 + 号的箭头 |

### 边缘检测区域

```
╔═══ 5px ═══╦════════════════════════════╦═══ 5px ═══╗
║  裁剪起始  ║   拖拽移动区域（中间）      ║  裁剪结束  ║
║  ◀▶      ║         ↔️                ║      ◀▶  ║
╚═══════════╩════════════════════════════╩═══════════╝
```

### 多选操作

- **框选**：按住鼠标左键拖拽矩形框，释放后选中框内所有 Clip
- **Shift + 点击**：追加选中 Clip
- **Cmd + 点击**：切换单个 Clip 选中状态
- **Cmd + A**：全选当前 Track 的所有 Clip
- **多选后拖拽**：同时移动所有选中 Clip（保持相对位置）

### Ripple Edit 模式

```
开启后，删除 Clip 会自动向左拉齐后续 Clip：

删除前:  [Clip A] ─── [Clip B] ─── [Clip C]
删除后:  [Clip A][Clip B] ─── [Clip C]
         ↑ 自动拉齐，无间隙
```

### Snap to Grid（网格吸附）

- **默认开启**：Clip 边缘自动吸附到时间标尺刻度（1s, 0.5s, 0.1s 根据 Zoom 自适应）
- **关闭吸附**：按住 `Cmd` 键拖拽，实现像素级精确定位
- **快捷键**：`N` 键切换吸附开/关

## 附录

### 响应式布局断点

| 窗口宽度 | 布局调整 |
|----------|----------|
| < 900px | 隐藏右侧边栏，元数据编辑改为 Modal 弹窗 |
| < 700px | 隐藏左侧边栏，文件列表改为下拉菜单 |
| < 500px | Mixer 强制折叠，仅显示 Master Fader |

### Zoom 级别

| 级别 | 1px 代表时长 | 适用场景 |
|------|--------------|----------|
| 25% | 1 秒 | 宏观查看整个文件 |
| 50% | 0.5 秒 | 粗略编辑 |
| 100% | 0.25 秒 | 默认编辑精度 |
| 200% | 0.125 秒 | 精确编辑 Clip 边界 |
| 400% | 0.0625 秒 | 样本级别精确编辑 |
| 800% | 0.03125 秒 | 最大放大（单个波形峰值可见） |

### 性能优化策略

1. **波形渲染**：使用异步 Peak Cache，256 samples/block，避免阻塞主线程
2. **频谱图**：Radix-2 FFT，O(N log N) 复杂度
3. **声能图**：Web Worker 计算 STFT，OffscreenCanvas 渲染
4. **电平表**：requestAnimationFrame 节流，每 16.67ms 更新一次
5. **Clip 移动**：transform: translateX() 替代 left，启用 GPU 加速
6. **虚拟滚动**：文件列表超过 100 项启用虚拟列表，仅渲染可见区域
