# FieldCorder DAW 使用说明书

## 一、项目简介

FieldCorder 是一款专为 macOS 设计的轻量级数字音频工作站（DAW），专注于多声道环境录音编辑。支持 2-6 声道音频，并提供 VST3/AudioUnit 插件托管功能。

---

## 二、主要功能

### 2.1 多声道编辑
- **支持声道数**：立体声（2声道）、四声道（4声道）、5.1 环绕声（6声道）
- **分声道波形显示**：每声道独立波形，颜色编码区分

### 2.2 音频插件
- **内置效果器**（无需额外安装）：
  - 3 段均衡器（EQ）
  - 高通滤波器（HPF）
  - 低通滤波器（LPF）
  - 压缩器（Compressor）
  - 混响（Reverb）
  - 延迟（Delay）
  - 增益（Gain）
- **第三方插件**：VST3 / AudioUnit（需编译原生插件）

### 2.3 专业电平表
- 实时峰值（Peak）
- RMS 电平
- True Peak（真峰值）
- LUFS 响度（ITU-R BS.1770-4）

### 2.4 通道混音器
- 每声道独立音量控制
- 静音（Mute）
- 独奏（Solo）
- 效果器插入

### 2.5 多文件工作流
- 拖放导入
- 文件队列管理

### 2.6 频谱分析
- 实时 FFT 显示
- 可配置窗口大小

### 2.7 非破坏性编辑
- 完整撤销/重做历史

## 四、基本操作

### 4.1 导入音频

**方式一：拖放**
- 将 WAV、AIFF 文件拖到编辑区

**方式二：菜单**
- `File` → `Import Audio` 或 `Cmd + O`

**方式三：文件队列**
- 点击工具栏 `Add Files` 添加多个文件

### 4.2 播放控制

| 操作 | 快捷键 |
|------|---------|
| 播放/暂停 | `Space` |
| 循环开关 | `L` |
| 倒放 | `R` |

### 4.3 编辑操作

| 操作 | 快捷键 |
|------|---------|
| 全选 | `Cmd + A` |
| 删除选区 | `Delete` / `Backspace` |
| 修剪到选区 | `Cmd + T` |
| 淡入 | `Cmd + F` |
| 淡出 | `Cmd + Shift + F` |
| 归一化 | `Cmd + Shift + N` |
| 增益 | `Cmd + G` |

### 4.4 缩放

| 操作 | 快捷键 |
|------|---------|
| 放大 | `+` / `=` |
| 缩小 | `-` |
| 左移播放头 | `←` |
| 右移播放头 | `→` |

### 4.5 标记点

- 添加 cue 点：`M`
- 删除 cue 点：选中后 `Delete`

### 4.6 撤销/重做

| 操作 | 快捷键 |
|------|---------|
| 撤销 | `Cmd + Z` |
| 重做 | `Cmd + Shift + Z` |

## 五、混音器使用

### 5.1 通道控制
每声道包含：
- **音量推子**（Volume）
- **静音**（Mute）
- **独奏**（Solo）
- **效果器插槽**：最多 4 个效果器

### 5.2 添加效果器
1. 点击通道上的 `+` 按钮
2. 从效果器列表选择：
   - 3-Band EQ
   - HPF / LPF
   - Compressor
   - Reverb
   - Delay
   - Gain
3. 调整参数

---

## 六、效果器说明

### 6.1 3-Band EQ
- **Low**：低频增益（-12dB ~ +12dB）
- **Mid**：中频增益（-12dB ~ +12dB）
- **High**：高频增益（-12dB ~ +12dB）

### 6.2 Compressor
- **Threshold**：阈值（-60dB ~ 0dB）
- **Ratio**：压缩比（1:1 ~ 20:1）
- **Attack**：启动时间（0.1ms ~ 100ms）
- **Release**：释放时间（10ms ~ 1000ms）

### 6.3 Reverb
- **Decay**：衰减时间（0.1s ~ 10s）
- **Wet/Dry**：干湿比（0% ~ 100%）

### 6.4 Delay
- **Time**：延迟时间（0ms ~ 5000ms）
- **Feedback**：反馈（0% ~ 90%）

## 七、导出

### 7.1 导出音频
1. `File` → `Export` 或 `Cmd + E`
2. 选择格式：
   - **WAV**：16-bit / 24-bit / 32-bit Float
   - **AIFF**：16-bit / 24-bit / 32-bit
3. 选择声道布局（Stereo / Quad / 5.1）
4. 可选：dithering（TPDF / Noise-shaped）

### 7.2 保存项目
- `File` → `Save` 或 `Cmd + S`
- 保存为 `.fcproj` 文件（JSON 格式，含嵌入音频数据）

## 十、故障排除

### 10.1 音频无声音
- 检查系统音量设置
- 确认播放头位置
- 检查通道是否静音

### 10.2 导入失败
- 确认文件格式支持
- 检查文件是否损坏

### 10.3 VST/AU 插件不工作
- 需要编译原生插件（见开发文档）
- 检查插件是否支持当前系统架构
